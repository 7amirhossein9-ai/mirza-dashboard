# راه‌اندازی ثبت‌نام و آدم‌های آنلاین در تالار میرزا

این بخش یک سرور کوچک و رایگان روی Cloudflare است که ایمیل‌ها، نام‌ها و آدمک‌ها را نگه می‌دارد.
بدون آن، تالار مثل قبل برای همه باز است. با آن، هر کس باید ثبت‌نام کند و بعد از گرفتن کد از تو وارد شود.

## مراحل (حدود ده دقیقه، همه رایگان)

۱. به dash.cloudflare.com بروید (همان حسابی که دامنه‌ی mirzainfo.ir در آن است).

۲. **Workers & Pages ← Create ← Create Worker**. نام را `mirza-auth` بگذارید و Deploy بزنید.
   بعد **Edit code** را بزنید، همه‌ی متن پیش‌فرض را پاک کنید، محتوای فایل `server/auth-worker.js` را بچسبانید و Deploy بزنید.

۳. **Storage & Databases ← D1 SQL database ← Create**. نام: `mirza-db`.

۴. به Worker برگردید: **Settings ← Bindings ← Add ← D1 database**.
   نام متغیر دقیقاً `DB` باشد و پایگاه `mirza-db` را انتخاب کنید.

۵. **Settings ← Variables and Secrets ← Add**: نوع Secret، نام `ADMIN_KEY`، مقدار یک رمز طولانی و دلخواه (دست‌کم ۸ نویسه، بهتر ۲۰ نویسه). این رمز مخصوص توست و به کسی نده.

۶. آدرس Worker را تعیین کنید. دو راه دارد:
   - **پیشنهادی:** در همان Worker، **Settings ← Domains & Routes ← Add ← Custom domain** و بنویسید `api.mirzainfo.ir`. (آدرس‌های workers.dev گاهی از ایران بسته هستند.)
   - یا همان آدرس `https://mirza-auth.NAME.workers.dev`.

۷. در فایل `config.js` سایت، این دو خط را پر کنید و ذخیره کنید:
   ```js
   const API_BASE = "https://api.mirzainfo.ir";
   const ADMIN_CONTACT = "آیدی تلگرام یا ایمیل شما";
   ```

۸. صفحه‌ی مدیر: `https://mirzainfo.ir/admin.html`. کلید `ADMIN_KEY` را وارد کنید.

## روال روزمره

۱. کسی ثبت‌نام می‌کند ← ایمیلش در لیست پنل مدیر می‌آید (وضعیت «در انتظار»).
۲. در پنل روی «ساخت کد» بزنید، کد شش رقمی را برایش بفرستید (پیام یا ایمیل خودتان).
۳. او در تب «کد فعال‌سازی» رمز و کد را می‌زند و وارد تالار می‌شود. از آن به بعد فقط با ایمیل و رمز وارد می‌شود.
۴. هر عضو آنلاین در تالار یک آدم است و نامش بالای سرش نوشته می‌شود.

دکمه‌ی «دانلود لیست ایمیل‌ها (CSV)» در پنل، همه‌ی ایمیل‌ها را به‌صورت فایل می‌دهد.

## نکته‌ها

- رمزها فقط به‌صورت رمزنگاری‌شده (PBKDF2 با نمک تصادفی) ذخیره می‌شوند و حتی تو نمی‌توانی ببینی.
- کد فعال‌سازی هفت روز اعتبار دارد و حداکثر شش بار می‌شود اشتباه زد.
- طرح رایگان کلودفلر: حدود صد هزار درخواست در روز. هر عضو داخل تالار حدود هر دو ثانیه یک درخواست می‌فرستد، پس برای ده‌ها نفر همزمان کافی است. اگر سایت پر بازدید شد، طرح پولی پنج دلاری بسته را برمی‌دارد.
